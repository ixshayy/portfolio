# Modern Portfolio Website

A sleek, responsive portfolio website built with React, TypeScript, and Tailwind CSS. Features a dark-themed design by default with light mode option.

## Features

- 🌙 Dark theme by default with light mode toggle
- 📱 Fully responsive design
- 🎯 Modern UI with smooth animations
- 🚀 Fast performance
- 📂 Project showcase with filtering
- 💼 Detailed project pages
- 📝 Technical blog/notes section
- 🎨 Consistent design system

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- React Icons

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/ixshayy/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Project Structure

```
portfolio/
├── src/
│   ├── components/     # React components
│   ├── contexts/       # React contexts (theme, etc.)
│   ├── data/          # Project data and content
│   ├── styles/        # Global styles and Tailwind config
│   └── types/         # TypeScript type definitions
├── public/            # Static assets
└── index.html         # Entry point
```

## Customization

1. Update your information in `src/data/projects.ts`
2. Replace images in `public/images/`
3. Modify theme colors in `tailwind.config.js`
4. Update content in components as needed
